# warikan-app

夫婦2人のための割り勘・精算アプリ。レシート1枚の「私・妻・共通」の仕訳と月末精算をラクにします。

**アプリ** → https://mitsu545.github.io/warikan-app/
（GitHub Pages。設定画面で GAS の URL と合言葉を入れると使えます）

## 中身

| 場所 | 中身 |
|---|---|
| `index.html` / `style.css` / `app.js` / `api.js` | アプリ本体（フレームワークなし） |
| `gas/コード.gs` | Google Apps Script。スプレッドシートに貼るコード |
| `docs/spec.md` | 仕様書 v2。作る前に必ず読む |
| `docs/setup.md` | Google 側のセットアップ手順 |

## いまの進み具合

| 段階 | 中身 | 状態 |
|---|---|---|
| 1 | シート7枚・保存と読み込み・アプリと接続 | 完了 |
| 2 | レシート写真をドライブに保存 | これから |
| 3 | Gemini でレシートを読み取る | これから |
| 4〜8 | 固定費・月末締め・精算の記録・分析・公開 | 画面はできている。GAS 接続はこれから |

段階3 が終わるまで「レシートを撮る」は見本の明細を出します。**送信と保存は本物**です。

## 構成

```
スマホ（GitHub Pages）→ GAS Web App → Googleスプレッドシート
                              ↓
                      Gemini API（段階3）／Googleドライブ（段階2）
```

> ⚠️ **このリポは public です。** Gemini の API キー・合言葉・GAS の URL は絶対に入れないでください。
> 合言葉と URL は GAS のスクリプトプロパティと、各スマホの設定画面（端末内）にだけ置きます。
