# デザインプロトタイプ（v2）

仕様書 v2（`../docs/spec.md`）の画面をダミーデータで確認するためのものです。

- GAS・スプレッドシート・ドライブにはつながっていません
- 送信・保存はしません（リロードで元に戻ります）
- レシート写真は canvas で描いた偽物です
- 本実装は「土台（GAS）を先に」の順で別途おこないます（仕様書 16 章）

`index.html` をブラウザで開いてください。

## 段階1 から：GAS に繋がります

設定画面に GAS の Web App URL と合言葉を入れると、ダミーデータではなく
本物のスプレッドシートを読み書きします（手順は `../docs/setup.md`）。

未設定のあいだはダミーデータのまま動くので、デザイン確認にも使えます。
